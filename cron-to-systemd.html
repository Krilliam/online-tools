Crontab to Systemd Timer Converter

Translate legacy crontab entries into modern, robust systemd .service and .timer units.

How to use

  1. Enter a name for your task (e.g., backup-db)
  2. Paste your existing crontab schedule (e.g., 0 2 * * *) or use @reboot
  3. Provide the absolute path to the command or script to execute
  4. Specify the user that should run the task
  5. Copy the generated files and follow the installation instructions
Supports standard 5-field cron or @reboot
