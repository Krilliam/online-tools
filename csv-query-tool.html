CSV Query Tool

Execute SQL queries on CSV files. Filter, group, join, and analyze data with SQL syntax.

How to use

  1. Configure upload settings (delimiter and header option)
  2. Upload one or more CSV files (max 50MB each)
  3. Write SQL queries using the file names as table names
  4. Click "Run Query" to execute and see results
  5. Export results to CSV or JSON, or copy to clipboard

Supported SQL: SELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY, LIMIT, OFFSET, JOIN, DISTINCT, aggregate functions (COUNT, SUM, AVG, MIN, MAX), string functions (UPPER, LOWER, TRIM, LENGTH, SUBSTRING, CONCAT), and operators (=, !=, <, >, <=, >=, LIKE, IN, BETWEEN, AND, OR, NOT, IS NULL, IS NOT NULL).
