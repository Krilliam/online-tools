CSV Query Tool

Execute SQL queries on CSV files. Filter, group, join, and analyze data with SQL syntax.

How to use

  1. Configure upload settings (delimiter and header option)
  2. Upload one or more CSV files (max 50MB each)
  3. Table names are the file names without extension (e.g., users.csv → users)
  4. Write SQL queries using the table names
  5. Click "Run Query" to execute and see results
  6. Export results to CSV or JSON, or copy to clipboard
SQL Syntax Reference

Table names: Use file names without extension (e.g., users for users.csv)

Basic queries:

SELECT * FROM users
SELECT name, age FROM users WHERE age > 25
SELECT * FROM users ORDER BY age DESC
SELECT * FROM users LIMIT 10 OFFSET 20

Filtering (WHERE):

WHERE age = 30
WHERE age > 25 AND city = 'Rome'
WHERE age BETWEEN 20 AND 40
WHERE city IN ('Rome', 'Milan', 'Naples')
WHERE name LIKE '%John%'
WHERE email IS NULL
WHERE email IS NOT NULL

Aggregation (GROUP BY):

SELECT city, COUNT(*) FROM users GROUP BY city
SELECT city, AVG(age) FROM users GROUP BY city
SELECT city, SUM(salary) FROM users GROUP BY city HAVING COUNT(*) > 5

JOIN (multiple files):

SELECT u.name, o.total 
FROM users u 
JOIN orders o ON u.id = o.user_id

SELECT u.name, o.total 
FROM users u 
LEFT JOIN orders o ON u.id = o.user_id

Operators: =, !=, <, >, <=, >=, LIKE, IN, BETWEEN, IS NULL, IS NOT NULL, AND, OR, NOT

Aggregate functions: COUNT(*), SUM(col), AVG(col), MIN(col), MAX(col)
