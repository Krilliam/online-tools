HTTP Status Codes Reference

Complete searchable reference of HTTP status codes with descriptions and usage examples.

How to use

  1. Type a status code (e.g., "404") or keyword (e.g., "not found", "redirect")
  2. Results update instantly as you type
  3. Use category filters to narrow by response class (1xx, 2xx, 3xx, 4xx, 5xx)
  4. Click any card to see full details
