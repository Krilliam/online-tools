SQL to JXSQL Translator

Convert PostgreSQL or MSSQL queries to JXSQL (Janox SQL) syntax.

How to use

  1. Paste your SQL query in the input field
  2. Select the SQL dialect (PostgreSQL or MSSQL)
  3. Click "Convert" to generate the JXSQL code
  4. Use "Copy" to copy the result to clipboard

Conversion rules:
• alias.column → JXCOL(alias:column)
• FROM table alias → FROM JXTAB(table:alias)
• FROM table (no alias) → FROM JXTAB(table)
• col1 || col2 (PostgreSQL) → JXCONCAT(JXCOL(...),JXCOL(...))
• col1 + col2 (MSSQL) → JXCONCAT(JXCOL(...),JXCOL(...))
• SUBSTRING(col, start, length) → JXSUBSTRING(JXCOL(...), start, end)
