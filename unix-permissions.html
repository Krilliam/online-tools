Unix Permission Calculator

Convert Unix file permissions between numeric (755) and symbolic (rwxr-xr-x) formats.

How to use

  1. Choose a conversion mode: "Checkboxes → Numeric" or "Numeric → Checkboxes"
  2. Toggle the checkboxes or enter a numeric value
  3. The conversion and chmod command update automatically
  4. Enable "Special bits" for setuid, setgid, and sticky bit
  5. Copy the chmod command to your clipboard
